# Codele

Codele — навчальна платформа з інформатики для школярів. Вона допомагає вивчати основи Python на практиці: читати умови, писати програми, запускати їх і самостійно виправляти помилки.

## Що можна робити

- Вивчати теми з програмування на прикладах і коротких поясненнях.
- Розв’язувати інтерактивні завдання з Python та одразу перевіряти результат.
- Отримувати підказки й бачити, як змінювався код під час розв’язання.
- Проходити тести, марафони й завдання, які призначив учитель.
- Створювати тести й задачі вручну або готувати їх за допомогою ШІ; для задач учитель може задавати персоналізовані варіанти.
- Стежити за власним прогресом, оцінками та медалями.

Учителі можуть працювати з класом: публікувати завдання й тести, переглядати роботи, давати оцінки та відзначати досягнення учнів. Помічники можуть долучатися до перевірки робіт.

Codele призначений для навчання та практики. Виконання завдань допомагає закріпити знання й краще зрозуміти, як працює код.
